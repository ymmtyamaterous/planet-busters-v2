# 戦略スペースバトルのオマージュ

## 概要・機能
- ターン制の戦略バトル
- 1 vs 1
    - 最初はcpuと人
    - 将来的に人対人
- 各ターンごとに、座標上に配置してある戦艦や戦闘機を移動するもしくは、敵の戦艦や戦闘機に向かって攻撃する
- 各プレイヤーは自分のメインの惑星を相手の攻撃から守りながら、相手の惑星を攻撃する
- 座標上には複数の道ができるように小惑星が配置されており、それらは破壊等できない
- 攻撃については確率でmiss,hit,criticalがある
- 戦艦や戦闘機には攻撃特性がある
    - 戦闘機にhitしやすいが惑星にhitしにくい等
- 攻撃を選択した場合は別windowを開いて攻撃アニメーションを再生
    - missのときはmissしたようなアニメーション、criticalのときは大爆発など
